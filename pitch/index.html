02
Инсайт

Ученик проваливает не ту тему,
которую ему дают решать заново

Школьник не справляется с квадратными уравнениями. Обычная платформа даёт ему ещё десять квадратных уравнений и фиксирует падение мотивации. Настоящая причина на два уровня ниже — потеря знака при раскрытии скобок.

Пока система не умеет спускаться по цепочке зависимостей между темами, она лечит симптом. Именно эту цепочку мы сделали ядром продукта, а не надстройкой.

03
Решение

AQYL — граф знаний плюс объяснимая модель освоения

Диагностика за 8 вопросов

Адаптивный тест выбирает вопрос там, где ответ несёт максимум информации об ученике.

Поиск первопричины

Обход графа предпосылок вниз: система называет тему, с которой действительно нужно начать.

Персональный маршрут

Топологическая сортировка графа, разложенная по неделям до даты экзамена.

Сократовский репетитор

Не выдаёт ответ: ведёт по лестнице подсказок до самостоятельного решения.

04
Как работает ИИ

Три модели, каждую из которых можно проверить

Bayesian Knowledge Tracing

P(тема освоена) обновляется по Байесу после каждой попытки с учётом вероятности угадать (0,22) и ошибиться по невнимательности (0,10). Даёт число, которое видит и ученик, и учитель.

Elo-рейтинг + IRT

Способность ученика θ и сложность задания b живут в одной шкале. Задание подбирается там, где предсказанная вероятность успеха ≈ 70 % — зона ближайшего развития по Выготскому.

Вывод по графу

Для непройденных тем оценка не выдумывается: априор из θ и b, потолок по слабейшей предпосылке, пол по освоенным следствиям. Каждый вывод трассируется до данных.

Никакого «чёрного ящика»: рядом с каждой рекомендацией в интерфейсе показаны факторы и их веса. Опционально подключается Claude API — тот же контекст уходит в облако одним промптом.

05
Продукт

Путь ученика — от «не понимаю» до плана на 8 недель

1 · Профиль и диагностика

Класс, предметы, цель, дата экзамена. Восемь адаптивных вопросов — и карта освоения по всем темам программы.

2 · Кабинет и карта знаний

Прогресс, слабые места, маршрут восстановления и интерактивный граф: видно, что от чего зависит и что заблокировано.

3 · Практика с разбором

Задание в зоне ближайшего развития, три ступени подсказок, разбор ошибки с названием типичного заблуждения, озвучка текста.

4 · Индивидуальный план

Недельный роадмап под дату экзамена с честным ответом: успеваешь или нужно N часов в неделю вместо текущих.

5 · Панель учителя

Тепловая карта класса 20 × 11, ученики в зоне риска, приоритет тем по эффекту вмешательства, добавление своих модулей.

6 · Геймификация и доступность

Опыт, серии дней, достижения. Три языка, светлая тема для проекторов, синтез речи, mobile-first.

07
Технологический стек

Ноль зависимостей — потому что это требование, а не эстетика

Фронтенд

Ванильный JavaScript (ES-модули), CSS с дизайн-токенами, хеш-роутер. Без сборки и без фреймворка: приложение открывается на школьном ноутбуке и слабом канале.

Данные и ИИ

Учебный граф и банк заданий в модулях JS, состояние в localStorage по схеме будущей БД. Модели BKT / Elo / IRT и вывод по графу — собственный код без библиотек, каталог src/engine.

Офлайн и деплой

Service worker (network-first с откатом в кэш), PWA-манифест. Разворачивается на Vercel / Netlify / GitHub Pages без CI. Опционально — Claude API из браузера.

Бизнес-модель

Бесплатно для ученика, платно для системы образования

B2C Free

Полный доступ ученику навсегда. Это не маркетинг, а условие социального эффекта: платный доступ отсекает ровно ту аудиторию, ради которой продукт создан.

B2B School — 250 ₸ / ученик / мес.

Панель учителя, аналитика класса и школы, свои модули, выгрузка отчётов для завуча.

B2G / НПО

Разворачивание на регион, интеграция с Kundelik, отчётность по разрыву город/село для управлений образования и донорских программ.

TAM 3,7 млн школьников РК SAM ~1,1 млн (7–12 классы, мат. и физ.) SOM 3 года: 60 000 учеников / 300 школ

Себестоимость обслуживания одного ученика близка к нулю: расчёты идут на его устройстве, серверу остаётся только синхронизация.

09
Социальный эффект

Что мы измеряем, чтобы не обманывать себя

Закрытые пробелы

Доля тем, перешедших из «пробела» в «освоено», на ученика за четверть.

Разрыв село / город

Разница среднего θ между сельскими и городскими школами внутри платформы.

Удержание

Доля учеников с ≥ 3 активными днями в неделю через 8 недель после старта.

Время учителя

Часы, сэкономленные на ручной диагностике класса, по опросу учителей.

Пилот: 3 школы Туркестанской области, 1 четверть, контрольная группа. Успех = сокращение разрыва по θ и рост доли закрытых пробелов относительно контроля.

10
Дорожная карта

Что уже работает и что дальше

Сделано (MVP)

14 тем графа, 42 задания с разборами на двух языках, адаптивная диагностика, BKT + Elo + вывод по графу, кабинет, конструктор плана, панель учителя, офлайн-режим, три языка, озвучка.

3 месяца

Supabase и синхронизация между устройствами, полный охват 7–11 классов по математике, банк заданий ЕНТ, распознавание фото рукописного решения, telegram-напоминания.

12 месяцев

Химия и биология, генерация заданий под конкретный пробел, интеграция с Kundelik, пилот на область, обучение модели на собственных данных прохождения.

Что в MVP является демо-данными: класс из 20 учеников для панели учителя сгенерирован детерминированным PRNG; всё остальное — реальные вычисления на реальных ответах пользователя.
